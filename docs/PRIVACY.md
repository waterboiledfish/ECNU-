# 隐私与数据说明

本应用是「本地优先」的：默认在你的电脑上运行，数据写入本机 SQLite。没有云端账号系统，也没有运营方服务器。

## 数据清单

| 数据 | 位置 | 用途 | 保留 |
| --- | --- | --- | --- |
| SSO 稳定标识 | `users.sso_subject` | 关联本地账号 | 至删号 |
| 昵称、头像、简介、专业、年级 | `users` | 个人资料与论坛展示 | 至删号 |
| 学习方向、课程、偏好 | `users.directions/courses/settings` | 推荐与默认设置 | 至删号 |
| 待办与提醒 | `reminders` | 到点提醒 | 至删除/删号 |
| 计划与打卡 | `plans`、`plan_progress` | 进度与连续记录 | 至删除/删号 |
| 单词复习状态 | `vocab_reviews` | SRS 复习安排 | 至删号 |
| 帖子、评论、点赞、收藏 | `posts`、`comments` 等 | 论坛功能 | 公开内容在删号后保留为匿名 |
| 私信 | `messages` | 一对一交流 | 至删除/删号 |
| 通知 | `notifications` | 站内消息 | 至删号/清理 |
| 举报与申诉 | `reports`、`appeals` | 社区治理 | 保留用于审计 |
| 官网文件与片段 | `documents`、`chunks` | 检索问答 | 管理员可删除 |
| 采集记录、审计日志 | `crawl_runs`、`audit_log` | 运维与追责 | 由管理员维护 |
| 头像文件 | `~/.ecnu-assistant/avatars` | 展示 | 至更换/删号 |
| 弹窗临时文本 | `~/.ecnu-assistant/popups` | 本机提醒 | 由系统临时文件清理 |

**不保存**：

- 学号密码、CAS ticket、OIDC access token / id_token；
- 用户模型 API Key（只存在浏览器 `sessionStorage`）；
- AI 问答正文（聊天记录仅在前端内存中，刷新即失）；
- 浏览历史、设备指纹、精确位置。

## API Key

- 用户在「模型设置」中填写，保存在当前标签页的 `sessionStorage`。
- 每次请求通过 `X-LLM-Key` 头发给本机服务；本机服务转发给用户选择的模型提供方。
- 服务端不写数据库、不写日志、不放进 URL；异常信息也不包含 Key。
- 关闭标签页后 Key 失效；可在设置中手动清除。
- 若部署在公网，请使用 HTTPS，防止链路上的中间人读取请求头。

## 使用第三方服务时的数据流向

| 场景 | 发送内容 | 接收方 |
| --- | --- | --- |
| 问答 / 摘要 / 教练 / 出词 | 问题、检索片段、对话上下文 | 你配置的 OpenAI 兼容模型服务 |
| 论文推荐 | 学习方向/检索词 | OpenAlex、arXiv |
| 今日热点 | 无用户数据；仅服务端拉取 RSS | 中国新闻网、界面新闻、IT之家、少数派等 |
| 可选新闻搜索 | 分类关键词 | Tavily（仅配置 Key 时） |
| 学习资料 | 年级、课程、方向生成的检索词 | B 站/小红书/抖音/知乎/MOOC 的搜索页（点击后由浏览器访问） |
| AI 审核（若部署方启用） | 帖子/评论文本 | 部署方配置的模型服务 |

使用第三方模型即表示你接受其数据处理条款；如果不希望内容离开本机，请不要配置模型 Key，或改用本地模型（OpenAI 兼容接口，例如 Ollama 的 `/v1`）。

## Cookie 与安全

- `ecnu_session`：登录会话，HttpOnly、SameSite=Lax、HTTPS 下 Secure。
- `ecnu_device`：仅演示模式用于绑定本地账号。
- `ecnu_sso_state`：CAS 登录一次性状态，10 分钟。
- CSRF token 存在会话表中，前端通过 `/api/auth/me` 获取，写请求带 `X-CSRF-Token`。
- 不接入广告、不接入第三方统计脚本。

## 匿名与可追溯

- 匿名帖对其他用户隐藏账号，显示 `匿名同学·xxxx`。
- 管理员和数据库保留真实作者关联，用于处理违法、诈骗、人身攻击等。
- 匿名不能对抗司法机关或学校依规调查；请在社区规范中如实告知。

## 用户权利

- **查看/修改**：个人设置页可修改昵称、头像、简介、专业、年级、方向、课程与偏好。
- **删除账号**：`DELETE /api/profile?confirm=DELETE`，前端在「个人设置 → 删除账号」。
  - 级联删除会话、待办、计划、私信、通知、关注等；
  - 公开发帖/评论的作者置空，显示「已注销用户」；
  - 举报与审计记录保留，用于社区安全追溯。
- **清除 Key**：模型设置中一键清除。
- **停止采集**：管理员可停止任务；删除数据目录即可清空全部本地数据。

## 数据备份与迁移

- 全部数据在 `ECNU_DATA_DIR`（默认 `~/.ecnu-assistant`）。
- 备份：停止服务后复制整个目录，或使用 SQLite 的 `.backup`。
- 迁移：把目录复制到新机器，保持相同路径或设置 `ECNU_DATA_DIR`。

## 日志

- 应用使用 Uvicorn 访问日志，仅路径与状态码，不含请求头、查询参数中的敏感信息（本应用也不把 Key 放查询参数）。
- 未处理的异常会打印堆栈，可能包含 URL 与内部变量；部署到公网时请限制日志访问权限。
- 采集失败只记录 URL 与错误类型。

## 部署方责任

如果你是部署者（而不是本机用户）：

- 在隐私政策中说明数据控制者、用途、留存期限与联系方式；
- 使用 HTTPS、限制管理员权限、定期备份；
- 配置 AI 审核时说明文本会发送给模型提供方；
- 遵守学校网络与信息安全规定，以及《个人信息保护法》等适用法律。
