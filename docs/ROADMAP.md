# 路线图

## v1.0（当前）

- 官网公开文件采集、BM25 检索、带链接引用问答
- 学业问答（独立模式、流式）
- 待办 / 重复提醒 / 四种提醒通道
- 定期计划、打卡、连续记录、单词 SRS、AI 教练
- 公共数据库入口
- CAS / OIDC 接入骨架 + 本地演示登录
- 论文推荐（OpenAlex / arXiv）
- 今日热点（多源 RSS + AI 摘要）
- 论坛：标签、匿名、评论、点赞、收藏、举报、申诉、关注、私信、通知
- 规则预筛 + 可选 AI 复核 + 管理员队列
- 学习资料推荐（B 站 / 小红书 / 抖音 / 知乎 / MOOC / 论文）
- 68 个后端测试、CI、Docker、部署与隐私文档

## v1.1（近期）

- [ ] 真实学校 SSO 的联调与回归（依赖学校审批）
- [ ] 采集增量更新：内容指纹、站点级刷新频率、失败重试
- [ ] 官网文档管理：下线失效文档、查看来源统计、采集任务历史
- [ ] 更细的检索：标题/正文分段权重、同义词、按时间加权
- [ ] 论坛：举报合并、管理员备注、禁言/封禁、申诉时限
- [ ] 提醒：桌面通知去重、静音时段、时区切换
- [ ] 计划：补打卡、计划模板、周报
- [ ] 无障碍与键盘操作完善，移动端细节优化
- [ ] 可选的 embedding 混合检索

## v2.0（中期）

- [ ] 多用户部署：PostgreSQL、Redis 限流、对象存储
- [ ] 定时全量采集与内容变更订阅
- [ ] 扫描版 PDF OCR
- [ ] 课程表 / 考试 / 成绩等校园数据接入（需学校授权）
- [ ] 桌面客户端（Tauri/Electron）或移动端
- [ ] 论坛内容分级、图片审核、通知偏好
- [ ] 论文收藏与阅读列表、引用导出
- [ ] 多语言（中/英）

## 不做的事

- 不模拟学校登录页，不采集需要登录的内容，不绕过访问控制。
- 不抓取 B 站 / 小红书 / 抖音 / 知乎正文，不提供盗版资料。
- 不把用户 API Key 或学号密码上传到任何自建服务器。
- 不在没有人工复核的情况下用 AI 自动封禁用户。

## 如何参与

从 `good first issue` 开始；涉及 SSO、采集、审核规则的改动请先开 Issue 讨论边界。见 [CONTRIBUTING.md](../CONTRIBUTING.md)。
