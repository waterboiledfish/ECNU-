# 内容审核与社区治理

论坛的目标是让同学愿意分享，同时把明显有害的内容挡在公共视野之外。审核采用「规则预筛 → 可选 AI 复核 → 人工复核 → 申诉」链路，**任何自动判断都不是最终裁决**。

## 规则预筛

规则文件：`app/data/moderation_rules.json`。当前类别：

| 类别 | 示例 | 处理 |
| --- | --- | --- |
| 色情低俗 | 约炮、裸聊、成人视频 | 命中即进入待审核 |
| 暴力血腥 | 砍死、血腥、炸弹 | 命中即进入待审核 |
| 违法违规 | 毒品、代考、假证、赌博、校园贷 | 命中即进入待审核 |
| 诈骗广告 | 刷单、兼职日结、加微信、荐股 | 命中即进入待审核 |
| 人身攻击 | 严重侮辱性词汇 | 命中即进入待审核 |
| 心理危机 | 轻生、自残等 | 一律转人工关怀，不做自动封禁 |
| 隐私泄露 | 手机号、身份证号、银行卡号、邮箱 | 触发待审核 |
| 垃圾内容 | 大量重复字符、过多链接 | 触发待审核 |

评分：

- 每个类别首次命中加该类别权重；多个类别可叠加，封顶 100。
- **≥ 85**：直接隐藏（`hidden`），进入人工队列。
- **30–84**：待审核（`pending`），仅作者和管理员可见。
- **< 30**：放行（`visible`）。
- `self_harm` 为 review-only：即使总分低也会转人工。

## 可选 AI 复核

配置服务端模型后启用：

```dotenv
ECNU_MODERATION_BASE_URL=https://api.deepseek.com/v1   # 可留空，默认同 LLM_BASE_URL
ECNU_MODERATION_API_KEY=sk-...
ECNU_MODERATION_MODEL=deepseek-chat
ECNU_MODERATION_FAIL_MODE=review   # AI 失败时：review（默认）或 open
```

- 在规则预筛后异步调用，提示词要求输出 `{risk, categories, reason}`。
- AI 只会把内容**收紧**（visible → pending/hidden），不会把规则命中内容自动放行。
- AI 失败时记录日志并按 `fail_mode` 处理；不会阻塞发帖。
- 未配置时完全使用本地规则。

**成本提示**：AI 审核使用服务端的 Key，与用户问答的 Key 分开，避免消耗用户额度。

## 人工队列

管理员在 `/admin` 查看：

- 内容审核：按帖子/评论、待审核/已隐藏筛选；看到真实作者（含匿名帖）与风险类别；可放行、隐藏、删除。
- 举报：按原因查看目标预览；可忽略、警告、隐藏、删除，并给举报人回复。
- 申诉：作者对 `pending/hidden/removed` 内容提交；管理员可通过并恢复或驳回。
- 用户：查看公开资料与发帖量。
- 审计：最近 50 条管理操作。

所有处理都会给相关用户发站内通知；审计日志写入 `audit_log`。

## 匿名机制

- 其他用户看到的昵称：`匿名同学·` + `HMAC-SHA256(secret, "anon:<post_id>:<user_id>")` 前 4 位。
- 同一帖子内同一作者稳定，跨帖子不可关联。
- 管理员接口保留真实 `author_id` 用于违规追溯。
- 匿名帖/评论被举报后，管理员仍能看到真实账号；这是平台治理的必要边界，需在社区规范中告知用户。

## 举报与申诉

- 举报原因：色情低俗、暴力血腥、违法违规、诈骗广告、人身攻击、隐私泄露、其他。
- 同一用户对同一目标只能举报一次；举报不会自动删除内容。
- 作者可对非可见内容提交申诉，同一目标仅允许一个待处理申诉。
- 恶意举报同样可能被管理员警告或限制。

## 运营建议

1. 明确社区规范与处罚阶梯（提醒 / 隐藏 / 删除 / 禁言），并在论坛侧栏固定展示。
2. 至少安排一名管理员每日查看一次队列；AI 审核不能替代值班。
3. 对涉及人身安全、隐私泄露、诈骗的内容优先处理。
4. 对心理危机内容，优先提供支持性回应与校内求助渠道，而不是简单删除。
5. 定期审查规则词表，避免误伤正常学术讨论（如法律、医学课程内容）。
6. 公示申诉渠道与处理时限。

## 已知限制

- 规则匹配不理解语境，可能误判；AI 也可能出错，所以必须人工复核。
- 图片/视频目前不做内容识别；头像上传只做格式与体积校验。
- 私信不做自动审核，收到骚扰可通过举报/管理员处理。
- 没有「禁言」「封号」等完整处罚系统；v1 以内容状态与警告为主。
- 匿名不是绝对匿名：管理员与数据库仍保留追溯能力；请不要发布违法内容。
