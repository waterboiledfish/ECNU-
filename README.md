# ECNU 小助手

面向华东师范大学学生的开源项目。当前仓库为产品设计与实施路线，尚无可用应用，也未获得学校官方授权。

## 目标功能

1. 官网文件问答：仅索引允许访问的学校官网文件，回答附原文 URL、发布日期和引用片段；证据不足时明确说明。
2. 学术问答：与校方政策问答分开，避免混淆来源。
3. 待办提醒：支持一次性、每日和每周计划；应用内及系统通知。Windows `cmd` 弹窗仅作为用户主动选择的本地方式，不执行提醒文本。
4. 学习计划：例如每日 20 个六级单词，记录完成和复习进度。
5. 公共数据库入口：由维护者确认目标地址后配置。
6. 校园 SSO：仅采用学校批准的接入方式；不采集或存储学号密码。
7. 论文推荐：基于用户自设方向，提供 DOI 或合法全文链接。
8. 今日热点：按科技、金融、娱乐等偏好搜索当天新闻，附来源与时间。
9. 论坛：经验、生活、寻物、学习分类；发帖、匿名展示、评论、私信、关注、举报、AI 预筛和人工复核。
10. 学习资料：按年级及课程推荐 Bilibili、小红书、抖音、知乎及论文的合法公开链接。

## 实施顺序

- 第一阶段：确定官方来源白名单、文件采集许可、问答引用规则和用户自带 API Key 方案。
- 第二阶段：桌面端待办、重复计划、提醒和学习计划。
- 第三阶段：经学校批准的 SSO、个人资料、论文与资料推荐、今日热点。
- 第四阶段：论坛、内容治理、私信和公共数据库入口。

## 安全与隐私

API Key 保存在用户设备的系统凭据库，不写入仓库、日志或服务端数据库。官方文档内容视作不可信输入，防范提示注入。SSO 应使用正式 OIDC、SAML 或 CAS 配置，不模拟学校登录页。论坛匿名只对其他用户隐藏身份，后台保留必要的违规追溯关联；AI 审核结果支持人工复核与申诉。采集和推荐需遵守来源网站的访问规则与版权限制。

## 上线前待确认

学校 SSO 接入申请及回调配置；可索引的官网域名与文件范围；公共数据库具体 URL；桌面端支持的平台；模型服务及 API 协议；论坛运营和内容审核责任人。

本项目与华东师范大学无官方隶属关系。

## 本地原型运行

需要 Python 3.11+，无需第三方依赖。在仓库根目录运行 `python -m app`，访问 http://127.0.0.1:8765。当前可使用本地待办、每日/每周重复计划及页面打开时的浏览器通知。数据保存在用户主目录的 `.ecnu-assistant/tasks.db`，不提交到仓库。其余模块在界面标为待接入。
